# エラーコード

Nearcade で問題が発生した場合は、標準化されたエラー コードが表示されます。

### ネットワークエラー
- **E10**: ICE 収集に失敗しました。ファイアウォールが WebRTC STUN トラフィックを完全にブロックしている可能性があります。
- **E11**: WebSocket のシグナリングが切断されました。ホストまたはトンネルがオフラインになった可能性があります。

### 入力エラー
- **E20**: 仮想コントローラーの作成に失敗しました (Windows)。 ViGEmBus がインストールされ、最新であることを確認してください。
- **E21**: uinput 権限が拒否されました (Linux)。ホストは適切な `/dev/uinput` 権限で Nearcade を実行する必要があります。

### オーディオエラー
- **E30**: ループバック デバイスのキャプチャに失敗しました。 UI をクリックして、オーディオ コンテキストのロックが解除されていることを確認します。
- **E31**: アプリケーション オーディオのブラックリスト登録に失敗しました。 PulseAudio/PipeWire バックエンドがエラーを返しました。

＃＃＃ 一般的な
- **E99**: 未処理の汎用例外。詳細については、開発者コンソール (`Ctrl+Shift+I`) を確認してください。

# ニアセックアーケード

Nearcade Arcade は、誰でも自分のアクティブなセッションを公開してリストできるグローバル マッチメイキング サービスです。

### セッションをリストする
ホスト セッションを開始するときに、[Live Arcade のリスト] トグルをクリックします。セッションは、すべての Nearcade ユーザーの [アーケード] タブにすぐに表示されます。

＃＃＃ 安全
- **直接 IP 漏洩なし**: トンネル (zrok、cloudflared) または VPS を使用している場合、実際のホーム IP アドレスは Arcade リストからマスクされます。
- **PIN 保護**: アーケード セッションでも PIN コードを強制できます。視聴者にはロビーが表示されますが、参加するには PIN を知っている必要があります。

### アーケードのハートビート
ホスト アプリケーションは、30 秒ごとに「ハートビート」ping をアーケードに送信します。 Nearcade を閉じるか接続が失われた場合、あなたのリストは 1 分以内に自動的に削除されます。

# Legalität einrichten

Nearcade umfasst leistungsstarke Funktionen für den Betrieb kopfloser, unbeaufsichtigter Spieleserver („Auto-Hosts“).

### Akzeptable Verwendung
Sie tragen die volle Verantwortung für die Spiele und Inhalte, die Sie über Nearcade hosten.
- Sie müssen die Rechte oder Lizenzen an der von Ihnen gehosteten Software besitzen.
- Die Nearcade Auto-Host-Funktion leitet Eingaben einfach an eine lokale Anwendung weiter.

### Kommerzielle Nutzung
Wenn Sie Nearcade für kommerzielle Arcade-Setups oder kostenpflichtige Cloud-Gaming-Dienste verwenden möchten, müssen Sie die EULAs der Spiele einhalten, die Sie streamen. Nearcade ist nur das Streaming-Protokoll; Es gewährt Ihnen keine kommerziellen Rechte an Spielen von Drittanbietern.

### Haftung
Die Autoren von Nearcade haften nicht für Kontosperrungen, Verstöße gegen die Nutzungsbedingungen oder Rechtsstreitigkeiten, die sich aus dem unbeaufsichtigten Hosten von Videospielen ergeben.

SpoutLibrary.dll
================
Source: Spout2 SDK (https://github.com/leadedge/Spout2), release 2.007.017
File:  Spout-SDK-binaries_2-007-017_1.zip / Libs_2-007-017/MD/bin/SpoutLibrary.dll

Spout2 (SpoutGL) is an open-source video sharing framework for Windows
(distributed under the BSD-2-Clause license, https://github.com/leadedge/Spout2).
SpoutLibrary.dll provides the C-API bridge used by Nearcade's Spout2 egress
worker (src/main/spout-egress-worker.js) to publish the host stream as a Spout
sender for OBS / Spout2-aware Windows applications.

The shared-memory Spout texture itself is owned by the local machine only;
this component performs no networking and no telemetry.

# Legalidade de configuração

O Nearcade inclui recursos poderosos para executar servidores de jogos autônomos e sem supervisão ("Auto-Hosts").

### Uso aceitável
Você é totalmente responsável pelos jogos e conteúdo que hospeda via Nearcade.
- Você deve possuir os direitos ou licenças do software que está hospedando.
- O recurso Nearcade Auto-Host simplesmente encaminha as entradas para um aplicativo local.

### Uso Comercial
Se você pretende usar o Nearcade para configurações comerciais de arcade ou serviços pagos de jogos em nuvem, você deve cumprir os EULAs dos jogos que está transmitindo. Nearcade é apenas o protocolo de streaming; não concede direitos comerciais a jogos de terceiros.

### Responsabilidade
Os autores do Nearcade não são responsáveis ​​por quaisquer banimentos de contas, violações dos Termos de Serviço ou disputas legais resultantes da hospedagem autônoma de videogames.
